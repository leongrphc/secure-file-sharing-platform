## Blockers and boundaries

The pinned MinIO image could not be pulled from Docker Hub (access denied) or Quay (401). MinIO therefore remains an optional Compose profile. The full stack and tests above use the working private local storage fallback. No live MinIO/S3 integration result is claimed.

This shared host ran low on disk during Docker builds. Temporary dependency backups and an unused full Chromium download created by this task were removed; unrelated containers, volumes and caches were left alone. Final builds and tests passed, but further image builds may require additional host disk space.

Initial checks exposed issues that were fixed and retested: missing Prisma generation after a clean install, dependency advisories (patched Next/Vitest and dependency overrides), a share-fragment state bug, a browser-test locator matching Next's route announcer, build-time proxy routing, and npm/sh signal forwarding in Docker. The container commands now execute Node directly after migrations so the API receives SIGTERM. The web gateway streams requests and responses, resolves the backend at runtime and keeps capability URLs out of proxy-failure logs.
